ATUALIZAR PARA v0.3

Feche o jogo e o instalador anterior. Extraia este ZIP inteiro em uma nova pasta.
Abra GranSagaLanguages.exe, selecione a instalação real e o idioma e clique em Aplicar.
Pode instalar diretamente sobre o inglês inicial/v0.2 ou PT-BR anterior compatível.
Não é necessário restaurar o russo antes. O backup original existente será verificado.

Não misture manifest.json ou patches de versões diferentes. Esta versão amplia os
menus; a história anterior é preservada. A tradução automática nova é um rascunho
para revisão, principalmente no inglês. Confira KNOWN-LIMITATIONS.md.

Para quem ainda não tem o jogo: instale e atualize o Gran Saga RU pelo 4game,
abra uma vez até a tela inicial, feche e só então use este instalador do mod.
Não precisa mudar o idioma dentro do jogo, instalar Python ou copiar traduções soltas.
Precisa de .NET Framework 4.8 ou superior. Use Iniciar-Launcher.cmd para verificar.
